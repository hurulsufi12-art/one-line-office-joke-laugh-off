`main.py` (Python 3.13, stdlib only) writes one original one-line office joke to `/output/entry.txt` as UTF-8 bytes, with no BOM and no trailing newline.

## Run

```sh
python3 main.py
```

## The joke

> I replied 'per my last email' to my own email, just to see how it feels to be gaslit by myself.

95 characters / 95 bytes (ASCII).
